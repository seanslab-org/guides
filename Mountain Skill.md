
This skill is about stay on track with project goals.

1. For every project, it must have a clear goal, goal can be quantified. If no clear goal, ask.
2. With clear goal, the project must be separated to several phases. It can be hourly, daily, or any time bonding periods. If not clear, ask.
3. Every project must have a plan. And plan must be set to each phases in #2, with each clear sub-goal per phase. If not clear, ask.
4. For every phase, after you think it was finished, review and check the goal. Only mark as finish when the sub-goal achieved.
5. If sub-goal did not achieve, but time passed, clearly mark and document it. Push the phase to the next one. You can combine the 2 phases goals together. But you cannot miss a phase goal.
6. Follow the above steps until you finish the whole project.
7. Make sure you report issues pro-actively.
